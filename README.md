# 牧羊犬比赛 · Sheepdog Trial

一个用 TypeScript + Canvas 2D + Web Worker 实现的牧羊犬比赛游戏。玩家用哨音指挥牧羊犬，
把远处山坡上的羊群赶过几道门，最后关进羊圈。

## 玩法

- **绕左 Come-by（Q）**：狗顺时针绕到羊群左侧包抄
- **绕右 Away to me（E）**：狗逆时针绕到羊群右侧
- **靠近 Walk on（W）**：从羊群正后方缓步压迫推进
- **停 Lie down（S）**：原地趴下，让羊群冷静下来
- **召回 That'll do（R）**：回到指挥位

狗听到哨音后，按自身的最大速度、加速度和转向角速度（惯性）跑向目标，不会瞬间变向。

## 羊群行为模型

每只羊每一步综合以下倾向，加权得到期望速度，再做带惯性的速度匹配：

1. **逃避狗**：个体躲避 + 群体共享逃逸方向。狗离得越近，压力越大（平方衰减），
   压力把整队沿「狗→质心」连线反方向推。
2. **跟随同伴**：抱团（cohesion）、对齐（alignment）、分离（separation）和头羊传导。
   头羊是平均前进方向上最靠前的羊，头羊转向会带动全队。
3. **找草吃草**：朝草地斑块走，压力一升高就迅速让位给逃逸。
4. **恐慌与脱群**：高压下个体噪声被放大（炸群），显著偏离群体密度的羊标记为脱群；
   狗贴得越近、压力越高，脱群阈值越窄，脱群的羊越多。
5. **轨道约束**：引擎层把羊群质心相对「狗→质心」推进轴的横向偏移用弹簧拉回，
   狗静止在正后方时轴固定、羊群走直线；狗绕到侧后方时轴旋转、羊群跟着转向。

压力随距离指数松弛，狗停得越远，羊群恢复吃草越快。

## 评分（对齐 ISDS 国际牧羊犬协会百分制）

| 环节 | 满分 | 说明 |
| --- | --- | --- |
| Outrun 围跑 | 20 | 狗出发绕到羊群后方的弧线质量 |
| Lift 起步 | 10 | 羊群是否被平稳惊起，炸群扣分 |
| Fetch 赶回 | 20 | 前半段过门，漏羊/门序错误扣分 |
| Drive 驱赶 | 30 | 后半段过门 |
| Pen 入圈 | 10 | 入圈与逃圈、未入圈扣分 |
| Shed 群羊完整度（改编） | 10 | 原作分羊环节，本游戏按脱群/贴脸压迫考核 |
| 时间罚分 | — | 超时每秒 0.5 分 |

单环节扣分不超过该环节满分，总分地板 0。

## 赛场与脾性

- 赛场：**青坡牧场**（直道新手场）、**蜿蜒谷地**（S 形门线多障碍）、**高寒荒原**（开阔门线长）
- 脾性：**沉稳群羊**、**惊弓群羊**（易炸群）、**倔头群羊**（恋草不怕狗）、**躁进群羊**（快而急）

## 四个页面

- `#/select` 赛场选择页：选赛场、脾性、羊只数量，查看评分规则与历史成绩
- `#/trial` 比赛页：Canvas 赛场 + HUD + 哨音指挥 + 回放控制
- `#/trial?debug=1` 羊群行为调试页：实时调 12 个行为参数，叠加逃逸圈/质心/推力可视化
- `#/results` 成绩页：ISDS 分项得分、失误明细、历史榜单

## 架构

```
src/
  shared/        纯数据与工具：向量、可种子化 RNG、类型、常量、赛场定义
  sim/
    sheep.ts     单只羊的受力与压力/脱群判定（纯函数）
    dog.ts       狗的口令运动学（速度/加速度/转向限制）
    scorer.ts    ISDS 评分记账
    engine.ts    模拟引擎：固定子步推进、过门/入圈判定、阶段状态机
    simWorker.ts Web Worker 封装（setInterval 固定 60Hz 节拍）
  render/
    renderer.ts  Canvas 2D 渲染器（只吃快照）
    simClient.ts Worker 的 Promise 化客户端
  ui/            四个页面与 hash 路由
tests/           Vitest：行为指标、ISDS 评分对账、DOM 页面测试
```

羊群计算全部在 Web Worker 中进行，主线程只接收结构化快照并渲染，保证画布不被模拟阻塞。

## 命令

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm test           # 运行测试（20 个）
```

## 关键行为指标（有测试覆盖）

- 狗从羊群正后方逼近时，质心移动方向与「狗→质心」连线夹角 ≤ 15°
- 狗停下后，羊群恢复吃草的时间随距离单调变长
- 狗贴得越近，脱群的羊越多；沉稳脾性比惊弓脾性脱群少
- 评分各环节满分与 ISDS 传统分值 20/10/20/30/10/10 完全对齐
